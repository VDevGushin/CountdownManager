# Countdown Manager v1.2.2

Countdown Manager — небольшое нативное приложение для строки меню macOS. Оно показывает, сколько дней осталось до отпуска, дня рождения, поездки или любого другого события. Учётная запись и подключение к интернету не требуются.

## Установка готового приложения

Готовая сборка рассчитана на Mac с Apple Silicon и macOS 13 или новее.

1. Откройте страницу [Releases](https://github.com/VDevGushin/CountdownManager/releases) и выберите последнюю версию.
2. Скачайте приложенный ZIP-архив с `Countdown Manager.app` и распакуйте его.
3. Перенесите **Countdown Manager.app** в папку **«Программы»**.
4. При первом запуске нажмите приложение правой кнопкой мыши, выберите **«Открыть»** и подтвердите запуск.

Приложение пока подписано локальной ad-hoc подписью и не нотарифицировано Apple. Поэтому обычный двойной клик при первом запуске может быть заблокирован. Если команда **«Открыть»** не помогла, откройте **«Системные настройки» → «Конфиденциальность и безопасность»** и разрешите запуск приложения там.

Если на странице Releases ещё нет готового архива или используется Intel Mac, приложение можно [собрать из исходников](#сборка-из-исходников).

## Как пользоваться

После запуска в строке меню появится **◷ Countdown**; отдельной иконки в Dock нет.

1. Нажмите **◷ Countdown**, затем кнопку `+`.
2. Укажите название, необязательную заметку, будущую дату и один emoji.
3. Нажмите **«Сохранить»**. Первый счётчик автоматически станет основным и появится в строке меню.
4. Нажмите звезду у другого события, чтобы сделать его основным. Карточка плавно переместится наверх.
5. Используйте меню `…`, чтобы отредактировать или удалить событие.

Автозапуск включается флажком **«Запускать при входе в macOS»** в нижней части меню приложения. По умолчанию он выключен.

## Возможности

- Любое количество счётчиков: название, небольшая необязательная заметка, будущая дата, один emoji, основной.
- Сегодняшние и прошлые даты запрещены в выборе и при сохранении.
- Основной счётчик показывается как `☀️ 238 дней`; первый автоматически становится основным.
- Звезда назначает основной счётчик; выбранная карточка плавно перемещается наверх и подсвечивается. Меню `…` позволяет редактировать или удалить.
- Перед удалением приложение запрашивает подтверждение.
- При удалении или наступлении даты основного выбирается ближайший оставшийся.
- В дату события оно весь день показывается как `Сегодня`. Прошедшие события удаляются следующей ночью, без архива. Проверка выполняется в полночь, после пробуждения, изменения часов/часового пояса, открытия меню и дополнительно каждые 30 секунд.
- «Приложение» → перезапуск или выход.

## Данные и приватность

Все события хранятся только на текущем Mac в файле:

`~/Library/Application Support/CountdownManager/countdowns.json`

Дни считаются по календарю, не делением секунд на 86400. Даты сохраняются как год/месяц/день; запись выполняется атомарно. При ошибке чтения файл не перезаписывается. Синхронизации, повторов и отсчёта после даты нет.

В локальную полночь значение каждого счётчика уменьшается на день. Когда наступает дата события, в карточке и строке меню появляется `Сегодня`; событие удаляется только после завершения этого дня.

Чтение, JSON-кодирование и запись выполняются вне главного потока, поэтому работа с файлом не блокирует интерфейс. Последовательное хранилище и номера ревизий защищают от перезаписи нового состояния запоздавшей операцией. Поля даты проверяются при чтении; некорректный календарный день считается ошибкой файла, а не исправляется автоматически.

## Диагностика

Приложение ведёт локальный журнал действий и ошибок, не записывая названия событий, заметки или emoji:

`~/Library/Application Support/CountdownManager/Logs/countdown.log`

Когда файл достигает 512 КБ, предыдущая часть сохраняется как `countdown.previous.log`. Журнал содержит запуск и завершение приложения, открытие формы, результат сохранения, изменение основного счётчика, ошибки чтения/записи и обнаруженные зависания интерфейса. Если главный поток не отвечает 5 секунд, фоновый сторож добавляет `ui.stall detected`; после восстановления — `ui.stall recovered`.

Для разбора проблемы сохраните оба файла журнала до следующего длительного использования приложения. Пользовательские названия, заметки и emoji в журнал не попадают.
Папку можно открыть из меню **«Приложение» → «Открыть папку диагностики…»**.

## Сборка из исходников

Нужны Git и Apple Command Line Tools (`xcode-select --install`) либо полный Xcode.

```sh
git clone https://github.com/VDevGushin/CountdownManager.git
cd CountdownManager
./build.sh
open "Countdown Manager.app"
```

Скрипт создаёт локально подписанный файл `Countdown Manager.app` в корне проекта. Перенесите его в **«Программы»** для постоянного использования. Сборка выполняется под архитектуру текущего Mac, поэтому исходники можно собрать и на Intel Mac.

## Проверки для разработчиков

```sh
swift run CoreChecks
swift run UIChecks
```

`Package.swift` также можно открыть в Xcode. Для распространения без предупреждения Gatekeeper потребуются сертификат Developer ID и нотарификация Apple.

Unit-проверки покрывают даты, CRUD, заметки и их границы, выбор и замену основного, жизненный цикл события в день наступления, JSON, переходы лет/летнего времени, високосный день и склонения. UI state-проверки используют тот же слой представления, что и SwiftUI: проверяют заметку, подпись «Сегодня», допустимость формы, перестановку и сохранение нового основного события на отдельном временном хранилище.

На машине разработки установлен только Apple Command Line Tools без полного Xcode, поэтому системные XCUITest здесь недоступны. `UIChecks` детерминированно проверяет состояния, которые использует SwiftUI, но не запускает системное accessibility-дерево и не измеряет покадровую плавность анимации. Эти визуальные аспекты проверяются вручную на установленном приложении.

## Управление проектом через ИИ

Владелец управляет продуктом и описывает задачи обычным языком, а ИИ отвечает за архитектуру, код, тесты, ревью, документацию и сборку. Правила находятся в [`AGENTS.md`](AGENTS.md), подробный процесс — в [`AI_WORKFLOW.md`](AI_WORKFLOW.md).

Команда владельца **«Собираем публичный релиз для пользователей»** разрешает повысить patch-версию, пройти полный test/review gate, собрать ZIP-архив, создать GitHub Release и проверить опубликованный файл. Версию можно задать явно: **«Собираем публичный релиз 1.3.0 для пользователей»**.

Нативные API: [NSStatusBar](https://developer.apple.com/documentation/appkit/nsstatusbar), [SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp).
