# Проверка копирования события

Снимки сделаны 9 ноября 2026 года из текущей рабочей сборки ветки `codex/event-copy`.
Версия пакета — 1.21.1/43. Исходники включают реализацию копирования, подготовленную
к отдельному коммиту после согласования интерактивного макета.

## Сборка и данные

- Компилятор использовал SDK macOS 15.4. Linked compatibility и deployment target — 13.0.
- Оформление — `native-calendar-graphite-v2` с общими нативными компонентами приложения.
- Набор содержит 14 PNG большого окна, мини-панели и редакторов в Light/Dark,
  включая оба варианта повышенного контраста редакторов.
- Сценарий использует отдельные JSON, файлы, настройки и управляемую календарную дату.
  В демонстрационных событиях есть выполненные подзадачи, ссылка и настоящий локальный PDF.
- Способ получения PNG — `NSView.cacheDisplay`. Геометрия и действия проверены
  внутри отдельного процесса приложения с production SwiftUI roots.

[Манифест снимков](manifest.json) содержит размер, окно, тему, контраст и SHA-256
исполняемого файла. [Происхождение сборки](NativeBuildProvenance.json) содержит SDK,
linked compatibility и хеши источников визуального контракта.

## Результаты

- Полный SwiftLint прошёл с нулём нарушений.
- `./verify.sh fast` прошёл, включая новые Core и Store regression workflows.
- `./verify.sh event-copy-capture` прошёл. Проверены 28-point действия обычной и основной
  карточек, фактический фокус NSDatePicker, даты источников, удержание черновика,
  межповерхностная резервация, Cancel с побайтовым сравнением JSON и состава файлов,
  нативный desktop sheet, изменение даты и Save с независимыми файлами и идентичностями.
- Источник 15 сентября 2044 года сохраняет дату в черновике копии. Для сохранённого
  прошедшего источника проверены сегодняшняя дата и пояснение.
- Владелец самостоятельно проверил отдельную тестовую сборку и сообщил, что сценарий работает.
  Тестовая сборка содержит тот же скомпилированный код и встроенную привязку к отдельному home.
  Переподпись меняет полный Mach-O хеш. Совпадение кода проверено на временных копиях
  executable со снятыми подписями.

[Результат нативного сценария](ui-smoke-result.txt) сохранён рядом со снимками.
Проверки в процессе устанавливают поведение управляемого сценария и итоговый вид окон.
Внешние действия строки меню, переключение Spaces, речь VoiceOver и визуальная плавность
промежуточных кадров требуют соответствующего внешнего или ручного наблюдения.

## Расширенный интерфейсный проход

Агент самостоятельно составил матрицу из 49 сценариев, затем добавил случай отмены
файлового диалога. Для каждого заранее определён ожидаемый результат. Проход выполнен
через внешние элементы macOS, обычные поля, кнопки и клавиатуру в отдельной QA-сборке
с семью исходными событиями и 33 файлами.

**Итог — 49 из 50 сценариев пройдены, один проверен частично.**

[Полный перечень с ожидаемыми и фактическими результатами](manual-checks.txt) и
[структурированные результаты](manual-checks.json) сохранены рядом со снимками.

Обнаружено старое сообщение об ошибке после успешного исправления недоступного файла
или восстановления записи JSON. Новая явная попытка сохранения теперь очищает предыдущее
сообщение, сохраняя новые ошибки и предупреждения очистки. В регрессионные тесты добавлены
проверки обоих путей. Полный fast и нативный capture повторно прошли на исправленном коде.
Оба пути ошибки вручную повторены в обновлённой QA-сборке.

[Ошибка до исправления](stale-error-after-save.png),
[успешный повтор в мини-панели](file-error-fixed-after-save.png) и
[успешный повтор записи в большом окне](write-error-fixed-after-save.png) показывают результат.

Частично проверен G03. Command-W сохранил изменённый черновик большого окна.
Отдельные физические клики по красной кнопке родительского окна и фону за листом остались
невоспроизведёнными. При открытом модальном листе текущий CUA target предоставляет только
сам лист и его элементы. Эти два действия требуют подходящего внешнего драйвера или
проверки человеком.

Свидетельства для названий, содержимого и обычных действий сохранены для путей,
незатронутых исправлением. Ошибки и перезапуск проверены на исправленной сборке.
После перезапуска побайтно совпали JSON и все сохранённые файлы. Итоговый аудит подтвердил
сохранность семи исходных событий, 33 исходных файлов приложения и внешних оригиналов.
После всех действий в профиле оставались 24 демонстрационные записи.
