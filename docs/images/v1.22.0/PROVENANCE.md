# Countdown Manager 1.22.0 — нативная проверка

Снимки финального пакета 1.22.0/44 получены 9 ноября 2026 года на отдельных демонстрационных
данных через LaunchServices. Пакет собран из чистой main на коммите
`dee06cf1b3556ce24b20edf411ccd8dcb95ac489`, отмеченном аннотированным тегом `v1.22.0`.
Исполняемый файл обеих нативных проверок совпадает с [аудитом пакета](artifact-audit.json)
и имеет SHA-256 `ff430dd40e87b2d796ba110438a8283bca6ae29020acbe4b5a2bd8c4515e2944`.

- Оформление соответствует native-calendar-graphite-v2.
- Компиляция использует SDK macOS 15.4 и linked compatibility 13.0.
- Копирование прошло три нативных сценария с кнопками обычной и основной карточек,
  фокусом NSDatePicker, Save/Cancel, независимыми файлами и датой 2044 года.
- Экран «Что нового» прошёл отдельный сценарий с новым содержимым и четырьмя
  вариантами темы и контраста.
- PNG получены через NSView.cacheDisplay из настоящих SwiftUI/AppKit окон.

[Манифест копирования](copy-manifest.json), [результат](copy-result.txt) и
[receipt](copy-receipt.json) фиксируют исполняемый файл и условия.
[Манифест описания релиза](help-manifest.json), [результат](help-result.txt) и
[receipt](help-receipt.json) фиксируют соответствующую проверку.
[Происхождение сборки](NativeBuildProvenance.json) содержит SDK и хеши визуального контракта.

[Расширенный интерфейсный проход разработки](../v1.21.1/event-copy/manual-checks.txt)
прошёл до подготовки версии. Его исправление включено в этот кандидат. Пункт G03 частично
проверен через Command-W. Отдельные клики по красной кнопке родителя и фону за модальным
листом требуют подходящего внешнего драйвера или проверки человеком.

[Публичная проверка](publication.json) подтвердила Latest, ZIP и оба адреса подписанного
канала. [Страница публикации](publication-browser.png) сохранена из встроенного браузера.
