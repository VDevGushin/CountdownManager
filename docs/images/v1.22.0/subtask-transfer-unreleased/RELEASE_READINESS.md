# Итоговая приёмка переноса подзадач

Завершено 16 ноября 2026 года в `codex/subtask-transfer`.

Проверенная рабочая сборка находится в `.build/subtask-transfer-ready/Countdown Manager.app`.
Её SHA-256 `adba7e1e9e61b6cfcf8012f50f0f3e2cdf189da68663cec0fe403f3591b3aef1`.
Версия разработки 1.22.0/44. [Receipt сборки](ready-candidate.json) и
[снимок исходников](ready-source-sha256.json) фиксируют проверенный вариант.

## Результаты

- Полный SwiftLint, CoreChecks и UIChecks прошли. [Финальный fast-журнал](ready-fast.log).
- Восемь source/design-проверок и 19 native-contract проверок прошли, включая защиту
  состава Xcode target и конфигурации клавиатурно доступного поля даты.
- Последовательный нативный прогон прошёл 14/14 групп на одном исходном пакете.
  Проверены общий интерфейс, сворачивание, редактор, три сеанса hide/show,
  desktop, вложения, погода, пустой список, создание недели, копирование,
  перенос одной подзадачи и стабильность редактора.
  [Общий журнал](ready-native.log), [сводка](ready-native/summary.tsv) и результаты
  каждого сценария сохранены в `ready-native`.
- 12 000 модельных вариантов проверили успешные и отклонённые переносы, точные снимки,
  порядок, UUID, лимит и JSON round-trip. [Результат](readiness-fuzz.log).
- Исходные [28 ручных сценариев](manual-qa.md) и последующая
  [расширенная приёмка](release-readiness-manual.md) сохраняют точные границы и версии.
- После согласованного временного включения Keyboard Navigation реально проверены
  Tab, Shift-Tab, Space, ввод по сегментам даты, меню, Cancel и сохранение переноса.
  Проведены сравнения A/B/C, включая воспроизведение и исправление пропуска даты.
- Реальные Reduce Motion и Increase Contrast включались для проверки. Keyboard Navigation,
  Reduce Motion, Increase Contrast и Reduce Transparency затем восстановлены
  в исходные значения `0 / false / false / false`, что проверено через UI и публичные getter.

## Исправленные находки

1. Устаревший полный снимок события, ожидавший переноса, мог вернуть или затереть пункт.
   `Store.save` отклоняет такой конфликт до записи. Четыре управляемые регрессии
   проверяют источник, получателя, независимое событие и отказ самого переноса.
2. В Xcode project отсутствовали ссылки трёх новых production Swift-файлов.
   Они добавлены. Регрессия защищает правильный target и Sources membership.
3. В раскрытой форме клавиатура пропускала дату. Поле приведено к работающей конфигурации
   обычного редактора — native field style, regular control size, minHeight 28 и FocusState.
   Автофокус, перехват клавиш и новый виджет не добавлялись. C прошёл прямой клавиатурный ввод.
4. Стрелка теперь сообщает средствами доступности, открыт или закрыт выбор даты.
5. Две старые проверки адаптированы к текущему интерфейсу и SDK. Заголовок проверяет четыре
   кнопки в одной системе нативных координат. Погодный тест определяет реальный picker
   по уникальному нативному выбранному заголовку и проверяет его enabled state и Москву,
   сохраняя отдельную внешнюю проверку всех 11 пунктов меню.

## Ограничения и точность свидетельств

Xcode `build-for-testing` прошёл. Запуск внешнего XCUITest-драйвера остановился до тестов
с `Timed out while enabling automation mode`. Средство Apple `automationmodetool` сообщило,
что режим выключен и его включение требует аутентификации владельца. Этот результат
не включён в число прошедших тестов приложения. [Журнал драйвера](xcode-driver-blocked.log).
Настройка разрешения автоматизации не обходилась.

Один общий нативный прогон был прерван потерей активности и реальной сменой Space
до проверки фокуса таймерного окна. События сохранены в исходных диагностических данных.
Повтор без вмешательства прошёл все 14 групп. [Прерванный журнал](initial-interrupted-native.log).

Прямая проверка речи VoiceOver, управляемая физическая смена Spaces и точная граница
ручного изменения размера окна остаются ограничениями внешнего драйвера. Для мини-панели
на C подтверждены клавиатурный вход в дату и редактирование, полное подтверждение клавишей
в прерванной внешней последовательности не засчитано. Общий компонент подтверждения
прошёл полный клавиатурный desktop-сценарий и нативный mini-сценарий.

В ранних протоколах было неточно сформулировано совпадение исходного executable и
переподписанной QA-копии. При смене QA bundle ID встроенная подпись меняет общий file hash.
В отчётах теперь разделены оба хэша. Независимо сверены все 37 file-backed Mach-O секций
каждой соответствующей пары. Код и данные секций совпали, отдельные receipts сохранены.
