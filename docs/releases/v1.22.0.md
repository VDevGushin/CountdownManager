## Reviewed changes

Feature and workflow changes entered main in `2d12258`. The copy action reuses the native
symbol-action group in desktop details and both mini-panel card families. It opens the shared
editor with source-date selection, inherited contents, reset subtasks and explicit Save/Cancel.
A saved copy receives independent event, child and file identities. The source remains available
with its own contents and file bytes. The copy favorite starts off. Failed copying or persistence
retains the draft, and a successful retry clears the earlier error.

The existing [product contract](../PRODUCT.md#copying-an-event),
[architecture](../ARCHITECTURE.md) and [verification map](../VERIFICATION.md#event-copying)
record the implemented boundaries. Project workflow and skill maintenance accompany the change.
