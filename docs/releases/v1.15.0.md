# Countdown Manager 1.15.0 / build 30

Статус: **проверенный подписанный production-кандидат, готов к публикации; ещё не опубликован**.
Предыдущий опубликованный выпуск — [1.14.1 / build 29](v1.14.1.md).

## Изменения

- Полноценное десктопное окно рядом с мини-панелью. Это одно приложение с общими событиями,
  избранным, погодой, темой и таймером; второй базы и синхронизации копий нет.
- Сетка и список с группировкой по месяцу и году. Одна карточка избранного — только при явном
  выборе; без звезды ближайшее событие не подменяет избранное.
- Детали события с заметкой, чек-листом и отдельными звездой, карандашом и урной. Удаление
  требует подтверждения без обязательного захода в редактор.
- Изменяемый разделитель с широкой зоной захвата; его положение сохраняется при действиях
  и переключениях. Каждая часть занимает не меньше трети рабочей ширины и 320 pt.
- Настройки внутри десктопного окна: заголовок слева, крестик справа; Escape и клик по
  затемнению закрывают панель, не активируя событие под ней. Черновик редактора защищён отдельно.
- Общие темы «Системная / Светлая / Тёмная». Контурная звезда нейтральная; только выбранная
  заполненная звезда акцентная. Оформление и навигация мини-панели сохраняются.
- Перестроение сетки/списка и групп чек-листа за 150 мс с отключением движения для Reduce Motion.
  Строки могут кратко пересекаться при перестановке; это не обещание идеальной compositor-анимации.
- Стабильное место погоды в шапке, карточках и деталях предотвращает сдвиги при появлении или
  исчезновении прогноза. Пустое место не выдаётся за погоду и не содержит ложных температур.
- Таймер остаётся в мини-панели и строке меню, не занимает место в большом окне и не сбрасывается
  при его закрытии. Закрытие окна не завершает приложение; выход — отдельное действие.

Формат и расположение данных прежние. Миграция, сброс событий и установка поверх приложения
в «Программах» в ходе подготовки не выполнялись.

Точный production-кандидат прошёл desktop **22/22**, mini **23/23**, editor **5/5**.
[64 свежих снимка и происхождение](../images/v1.15.0/PROVENANCE.md).
Ранее принятые внешние настройки **1/1** и запись перестановки чек-листа **1/1** остаются
адресным evidence неизменённых обработчиков, а не новым полным внешним регрессом.

Финальные внешние маршруты латинского ввода и настоящего Save диагностики приняты **2/2**:
исходный лимит 150 символов, фокус/Undo и Cancel → повторное открытие → ввод пути → настоящий Save.
ZIP независимо проверен: только summary/log версии 1.15.0/30, без событий, настроек и тестовых
текстов; JSON событий неизменён. [Сводка](../images/v1.15.0/preflight-input-diagnostics.json).
Реальное изолированное обновление 1.14.1/29 → 1.15.0/30 через штатные окна Sparkle также принято:
загрузка подписанного архива → извлечение → Install and Relaunch → новый процесс на прежнем пути.
Хеш новой тестовой копии совпал с ожидаемым; байты событий и сохранённое состояние списка остались
прежними. После Install приложение вручную не запускалось. [Протокол](../images/v1.15.0/actual-update.json).
Первый предрелизный XCTest на русской раскладке потерял латиницу даже в системном PathTextField;
это воспроизведение ограничения драйвера вне Countdown, не доказанный дефект формы приложения.
Пользователь переключил источник на ABC; повтор прошёл без ослабления проверок и без clipboard-обхода.

## Ограничения

Apple Silicon, macOS 13+, ad-hoc, без нотарификации Apple. Старые macOS, Intel и первая установка
через Gatekeeper физически не сертифицируются этой подготовкой. Реальные Spaces/несколько
мониторов и полная VoiceOver-приёмка не заявляются. Нативные снимки и синтетическая погода
не подтверждают реальные разрешения геолокации, всех сетевых провайдеров или другой Mac.

Обновление проверено на реальной старой 1.14.1 и новом кандидате с отдельными test ID, общим
размеченным home, loopback feed и одноразовым тестовым ключом. Переподпись тестовых копий меняет
Mach-O signature bytes; нормализованные исполняемые данные совпадают с оригиналами. Для доступа
автоматизации к старой мини-панели использован штатный `--xcui-testing`, подавляющий её автоскрытие;
новая копия перезапущена самим Sparkle без этих аргументов. Это не новая сертификация production
auto-hide старой панели. Защита редактора/таймера проверена отдельными регрессиями, не повторена
в этом обычном update-переходе. Production ZIP/feed проверены отдельно прежним публичным ключом.
