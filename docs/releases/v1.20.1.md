## Problem and correction

A downloaded update could appear unresponsive after `Установить и перезапустить` from desktop
Settings. A read-only native SwiftUI sheet prevented AppKit's quit event before the application
delegate could perform the restart-safety check. Mini-panel Settings has no native sheet, so the
same update succeeded there. `DesktopSheetTerminationPolicy` now lets read-only Settings and
attachment sheets deliver the quit event. Event editors and text composers retain native protection.
The existing editor, persistence/recovery, timer and diagnostics guards are unchanged.

The native `Что нового` release ID is `1.20.1`; its content explains the correction and preserved
safety guards. Controller, layout, dismissal and admission policy are unchanged. All 1.20 event
retention and 1.19 material/link workflows remain included.
