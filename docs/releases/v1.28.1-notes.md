# Countdown Manager 1.28.1

Fixed an error that could reject PDFs, ZIP archives, and other ordinary files dragged from Finder onto events or Records. The file retains its name, and Countdown Manager saves a local copy.

## По-русски

Исправили ошибку, из-за которой PDF, ZIP и другие обычные файлы из Finder могли не добавляться к событиям и записям. При добавлении Countdown Manager сохраняет локальную копию с исходным именем.

**1.28.1 · сборка 54 · Apple Silicon · macOS 13+.**
