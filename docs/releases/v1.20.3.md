## Change

The alarm emoji in the mini-panel's running/finished timer was constrained to a 20-point width.
`fixedSize()` preserves the full glyph inside the existing slot. Timing, persistence and status-item
behaviour are unchanged. The native release-help text and embedded update notes describe this fix.
[Apple's layout semantics](https://developer.apple.com/documentation/swiftui/view/fixedsize()).

The repository homepage was still on 1.18.1 because later releases had not reached default `main`.
README now describes the current product and Graphite design, without old release galleries.
PRODUCT/ARCHITECTURE/DESIGN release-help references and UPDATES were reconciled; local links were
checked across maintained project documents. Per-version reports remain evidence for their own runs.
