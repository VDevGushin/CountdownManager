# Countdown Manager 1.28.0 — Records

- Records keep descriptions, checklists, files and links without a date. Open **Records** in the mini panel or desktop window.
- Add a record from the shared list header in the mini panel. The desktop remembers the search and selection for each section.
- Drop files and links onto events or records. Bookmarks dragged from Safari’s address bar keep their title and link.

## По-русски

- В разделе **«Записи»** можно хранить описания, подзадачи, файлы и ссылки без даты. Раздел доступен в мини-панели и большом окне.
- В мини-панели кнопка добавления находится в общей шапке списка. Большое окно запоминает поиск и выбор для каждого раздела.
- Перетаскивайте файлы и ссылки на события или записи. При переносе из адресной строки Safari сохраняются название страницы и ссылка.
