# Countdown Manager 1.18.0 / build 33

Статус: **готов к публикации — READY_TO_PUBLISH**. Локальная предрелизная приёмка завершена.
Публичная HTTPS-доставка и Latest проверяются после публикации. До этого подтверждённый
публичный выпуск — [1.17.0 / build 32](v1.17.0.md).

## Изменения

- Полка вложений: первые четыре файла в двух колонках большого окна и первые три в одном ряду
  мини-панели. Остальные доступны через «Показать все N»; пустой раздел скрыт.
- Компактные детали события: название с небольшим календарём, общая строка даты и температуры,
  согласованные заголовки разделов и скрытая пустая заметка.
- Быстрый нативный просмотр: крупное превью, переход к предыдущему/следующему файлу,
  возврат к исходному списку с прежними поиском и прокруткой, явное «Открыть в приложении».
- Исправлена область нажатия всей строки файла и исключение скрытой библиотеки из accessibility.
  Поздние запросы отменяются; закрытие сохраняет содержимое до завершения системной анимации;
  скрытие окна освобождает нативный renderer.

Дата события, подзадачи, лимит 15 новых вложений и сохранность старых коллекций остаются прежними.
Приложение хранит собственные копии; исходники не меняются. После даты или удаления события
удаляются и его копии. Формат данных и стабильный Sparkle-канал не меняются.

## Границы

Целевой runtime preflight — macOS 26.6.2 / 25G83 / arm64. Требования пакета остаются
Apple Silicon и macOS 13+. Запуск на macOS 13, настоящий VoiceOver и все сторонние Quick Look
providers отдельно не сертифицируются. Нативный просмотр best-effort; недоступное содержимое
сохраняет понятный fallback. Превью видео не является обещанием встроенного универсального плеера.
Ad-hoc и Ed25519 не означают Apple notarization; первая установка остаётся отдельной границей.
