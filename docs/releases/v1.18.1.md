## Changes

- Unmodified Left/Right arrow keys navigate saved attachments in the desktop and mini-panel
  quick preview, using the same actions as its visible buttons. Navigation follows the whole
  saved event order even when opened from filtered search, and stops at the first/last file.
- Desktop event details separate date and forecast with spacing instead of a middle dot,
  matching feed and favorite cards. The mini-panel's existing date layout is unchanged.
