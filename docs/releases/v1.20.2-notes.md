# Countdown Manager 1.20.2 — графитовая тёмная тема

Тёмная тема получила нейтральные графитовые фоны и светлый текст без кремового оттенка.
Новая палитра применяется в большом окне, мини-панели, редакторе, настройках, материалах,
подтверждениях, «Что нового» и уведомлении таймера. Коралловые календари и цвета состояний сохранены.

Нативные окна и меню получают выбранный светлый или тёмный режим приложения.
**Ограничение:** календарь и файловые диалоги macOS могут сохранять системное тонирование
цветами обоев. Этот выпуск не устраняет его и не меняет общесистемные настройки.

Светлая тема, компоновка, события, подзадачи, вложения, ссылки и защита перезапуска обновления
сохранены. Содержимое документов и фотографий не перекрашивается.

Обновитесь через **Настройки → Проверить обновления…**. Для первой установки из 1.20.0
используйте настройки мини-панели либо закройте настройки большого окна перед установкой.
Открыть описание выпуска снова: **Настройки → Что нового…**.
