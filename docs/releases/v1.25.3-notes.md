# Countdown Manager 1.25.3 — мини-панель в строке меню

На macOS 27 значок снова открывает и закрывает мини-панель после возврата из большого окна. Он остаётся подсвеченным, пока панель открыта. Открытие и закрытие плавные, а «Уменьшение движения» отключает переходы.

Обновиться можно через **Настройки → Проверить обновления…**.

1.25.3 · сборка 50 · Apple Silicon · macOS 13+.
