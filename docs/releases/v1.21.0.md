## Changes

`Создать день` adds a reviewed one-time batch from tomorrow through Sunday. Thursday offers
three dates; Saturday offers one. On Sunday the command becomes `На следующую неделю…`
and offers the following Monday–Sunday. The desktop menu, mini-panel inline choices and genuine
empty state expose the same range. Preview and Cancel write nothing; explicit Create saves only
missing marked days through one event-data write. Existing ordinary same-date events and favorite
are preserved. A stale civil-day preview requires another explicit confirmation of the new range.
There is no recurrence, template library, persisted week group or group-level Undo.

The desktop's native event-card Button now uses `.borderless` rather than `.plain`, avoiding the
additional disabled-state fade during ordinary editor opening/closing. The real Button, native
sheet, layout ownership, hit-testing, accessibility and shared-session guards remain in place.

Day-origin identity and the exact legacy fallback are documented in
[PRODUCT](../PRODUCT.md#creating-days-through-the-end-of-the-week). They do not depend on guessing
weekday-looking titles. Current decoding compatibility is not a promise that an older writer
preserves new metadata when writing the same file.
