# Countdown Manager 1.17.0 / build 32

Статус: **локальные проверки и подписанные артефакты готовы; не опубликован**.
Последний опубликованный выпуск — [1.16.0 / build 31](v1.16.0.md).
Финальный кандидат 1.17.0/32 прошёл адресную нативную проверку, fast-регрессии,
независимый аудит подписей и реальное изолированное обновление. Тег и публичные
загрузки ещё не подтверждены. Локальная готовность не означает публикацию.

## Изменения

- Иконка приложения использует те же цвета Марса, что и строка меню. Светлая палитра:
  плитка `#f5f1e8`, планета `#303038`, полоса `#b44e38`; тёмная: плитка `#211c19`,
  планета `#f0eee9`, полоса `#ef9b81`. Полоса цветная, три кратера показывают фон плитки.
- При открытии мини-панели или основного окна Марс **только в строке меню** делает один
  равномерный полный оборот за 12 секунд и останавливается в исходном положении.
  Иконка Dock остаётся статичной с новой палитрой.
- Вращение доступно только для Марса без активного избранного и таймера. Выбор избранного
  или запуск таймера прекращает оборот; удаление таймера не возобновляет прерванный цикл.
  Следующее открытие может начать новый оборот. Обычные обновления состояния не запускают его.
- «Уменьшение движения» отключает вращение и останавливает начатый оборот. Отключение
  этой системной настройки само по себе не запускает новый цикл.

Формат событий, данные вложений и их жизненный цикл сохраняются. Обновление не требует
миграции или сброса пользовательских данных. Production bundle ID и стабильный Sparkle feed
остаются прежними; выпуск использует существующий ключ подписи обновлений.

## Предрелизная проверка

[Финальный кандидат](../images/v1.17.0/candidate-receipt.json) имеет executable SHA-256
`7b50b24d55c1e3abab64ae87af46170619551fd445a5bd1b4e114cb4dcc00a2d`.
Strict SwiftLint — **0 нарушений / 73 файла**. Итоговый `verify.sh fast` завершился с кодом 0:
CoreChecks и UIChecks прошли, включая матрицы поворота, постоянный центр, явную очистку,
повторный запуск и подавление движения.

[Нативная строка меню](../images/v1.17.0/menu-identity/ui-smoke-result.txt) — **3/3** за
**22,221 с**, 24 PNG. Проверены настоящие callbacks открытия панели и desktop, промежуточные
quarter/half-положения, приоритет таймера без возобновления прерванного оборота, окончание
цикла и повторное открытие. Содержимое Dock и события остаются неизменными.
[Нативный desktop](../images/v1.17.0/desktop/ui-smoke-result.txt) — **27/27** за **50,843 с**,
110 PNG с изолированными демонстрационными данными. Эти результаты относятся к указанному
финальному executable, а не к отменённому прототипу с вращением Dock.

Первая status-only попытка завершилась FAIL на ожидании окончания оборота и сохраняет
свой исходный результат. Финальный код явно удаляет именованную Core Animation после
одного цикла; свежая успешная проверка не превращает старую попытку в PASS.

Нативные снимки и параметры Core Animation не подтверждают воспринимаемую плавность,
физический ввод по строке меню или поведение на всех поддерживаемых macOS. Команды и
границы доказательств описаны в [VERIFICATION.md](../VERIFICATION.md) и [UPDATES.md](../UPDATES.md).

## Реальная проверка обновления

[Финальный протокол](../images/v1.17.0/genuine-update-final.json) подтверждает изолированный
переход реальной **1.16.0/31 → 1.17.0/32** через Sparkle. Старый PID **32729** сменился
единственным автоматически запущенным процессом **32940** по тому же пути приложения.
Новый процесс обнаружен независимым наблюдателем до повторного чтения UI и без ручного
открытия приложения после Install.

JSON с двумя вымышленными событиями сохранился побайтно, включая подзадачи и избранное;
сохранена тёмная тема. Тест использовал отдельный bundle ID, изолированный home, локальный
HTTP и одноразовый ключ. Unsigned код финального production-кандидата не изменён.
Пользовательские данные и production-приложение не использовались как тестовые fixtures.
Этот результат не подтверждает публичный HTTPS или первую установку.
