## Change and explicit limit

Dark application surfaces now use the accepted Graphite palette instead of brown backgrounds
and cream text. This includes desktop, mini-panel, editor, settings, material libraries/preview
shells, inline confirmations, release help and completion alert. Light, coral/semantic colors,
layout, data schema and update restart guards are preserved. Native application windows and menus
receive the selected appearance; file dialogs and the completion alert inherit their owner.

**Native macOS date popovers and file dialogs may retain system desktop/wallpaper tinting.**
The user's screenshots establish this visual exception. Wallpaper tinting itself has not been
confirmed by a local A/B test. No system preference was changed. This is disclosed in native
help, Markdown/HTML release notes and README; the release does not claim its removal.
