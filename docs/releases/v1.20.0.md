## Changes

- The event editor adds `Сохранять после даты события` as its third native checkbox, below
  weather and primary selection. It is off for ordinary/day creation and older stored events.
- Saved retention keeps the date, identity, note, tasks, links and owned file copies after the
  date. Labels become `Вчера` or `N дней назад` in secondary ink. The explicit primary remains
  above the list and in the menu; other past events are last, recent first. Desktop uses a final
  `Прошедшие` group; mini keeps a plain list without extra groups or a separate archive.
- Existing retained past dates may remain unchanged while editing or move to today/future.
  Unchecking past retention and Save requires explicit deletion confirmation; cancellation
  preserves the event and draft. Durable deletion removes owned copies while keeping originals.
- The existing native `Что нового` window has release ID `1.20.0` and three current instructions.
  Its safe admission, shared component treatment, Escape/Return and manual reopening are unchanged.

## Compatibility

The production identity, stable HTTPS feed and signing key are unchanged. The canonical build
uses headers SDK 15.4, linked compatibility/minimum macOS 13.0 and `native-warm-calendar-v1`.
Existing missing `keepsAfterDate` flags decode as false, without migrating dates or inferring
retention from primary status or materials. Old writers do not understand retention and can
expire past events and their owned copies; downgrade recovery requires matched JSON and
`Attachments/` backups. Saved links still require the compatible 1.19.0-or-newer schema.

## Limits

A genuine **1.19.0 → 1.20.0 Sparkle installation/relaunch was not exercised** in this release task.
Historical update evidence is not presented as acceptance of this payload.

Controlled civil-clock transitions do not establish physical midnight/sleep-wake timing. Native
render captures show settled frames rather than compositor motion or absence of flicker. The
new feature does not change status-item/Spaces routing. External confirmed deletion, VoiceOver,
IME, every cross-app drag/provider and every supported macOS runtime remain outside new evidence
unless explicitly recorded during final release acceptance.
