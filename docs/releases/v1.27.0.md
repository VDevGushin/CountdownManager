# Countdown Manager 1.27.0 / build 52

English is the default. The app has a shared language chooser and a macOS 27 fix for reopening
the mini-panel after switching apps. [Release notes](v1.27.0-notes.md)

Native tests on macOS 27.2.1 verified immediate switching in both Settings surfaces, selection
and timer continuity, language persistence, and the two status-item reopening scenarios.
Isolated runs in both languages verified native date formatting and retained the open editor's
draft, focus, timer deadline and exact event bytes while switching.

The release package and publication are tracked separately from source validation.
