# Countdown Manager 1.27.0 — English and Russian

- English is now the default. Choose **Settings → Language** in the main window or mini-panel to switch immediately. Automatic weekday titles follow the interface language. Your titles, notes, and subtasks are preserved.
- Fixed a macOS 27 issue where the first menu-bar click could fail to reopen the mini panel after switching to another app.

## По-русски

- Английский теперь язык по умолчанию. Чтобы включить русский, выберите **Settings → Language → Русский**. Язык меняется сразу. Автоматические названия дней меняются вместе с языком интерфейса. Свои названия, заметки и подзадачи сохраняются.
- На macOS 27 первый клик по значку после переключения в другое приложение снова открывает мини-панель.

**1.27.0 · сборка 52 · Apple Silicon · macOS 13+.**
