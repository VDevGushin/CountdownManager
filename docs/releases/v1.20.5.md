## Change

The shared native note editor now retains complete typing, paste, replacement and committed IME
input above the saved-note allowance. The actual N/150 counter turns red and Save remains disabled
until shortened. Previously over-limit input was rejected without explanation, so paste appeared
broken. This matches the existing subtask editing pattern.

The existing domain and persistence limits remain authoritative: 150 graphemes for new notes;
max(150, currently saved note length) for an existing active event. Unchanged legacy notes remain
saveable. Native selection, Undo, draft Cancel and scrolling are preserved. There is no data migration.
The owner accepted this interaction and requested the fix and release in the current chat.
