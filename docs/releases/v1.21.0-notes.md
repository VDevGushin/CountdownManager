# Countdown Manager 1.21.0 — дни до конца недели

## Дни до конца недели одним действием

В меню **«Создать день»** появился вариант **«До конца недели…»**. Он подготавливает
отдельные дни с завтрашнего по воскресенье: в четверг — три дня, в субботу — один.
В воскресенье действие меняется на **«На следующую неделю…»** и предлагает семь дней,
с понедельника по воскресенье.

Перед созданием видны все даты. Уже созданные дни пропускаются, а обычные события
на этих датах сохраняются. Подтвердите список кнопкой **«Создать N дней»** или нажмите
**«Отмена»**. Действие доступно в большом окне, мини-панели и пустом списке.

Это разовое создание отдельных дней: без повторяющегося расписания, шаблонов и групповой отмены.

## Спокойное открытие редактора

При открытии и закрытии обычного редактора в большом окне убрано дополнительное изменение
яркости фоновых карточек. Редактор по-прежнему сохраняет изменения только после
**«Сохранить»**; **«Отмена»** возвращает к списку без сохранения черновика.

Обновление: **Настройки → Проверить обновления…**.
