Исправлено обновление из большого окна

Кнопка «Установить и перезапустить» при обновлении из настроек основного окна теперь завершает установку без перехода в мини-панель и ручного закрытия настроек.

Открытый редактор, сохранение данных, работающий таймер и экспорт диагностики по-прежнему откладывают перезапуск. Сохранение событий после даты, ссылки, файлы и текстовые вложения работают как в 1.20.

Как установить этот патч из 1.20.0

Откройте Настройки в мини-панели → «Проверить обновления…», затем скачайте и установите обновление.

Если обновление уже скачано из большого окна, закройте его настройки перед нажатием «Установить и перезапустить». Первую установку выполняет ещё старая версия с багом. После установки исправление будет работать для следующих обновлений.

Экран «Что нового» внутри приложения обновлён. Открыть его снова можно через Настройки → Что нового….
