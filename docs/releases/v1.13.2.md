## Ограничения

Приложение ad-hoc signed, без нотарификации Apple; подготовленный бинарный файл — arm64.
Внешняя клавиатура, VoiceOver speech, реальная IME-сессия, Gatekeeper первой установки,
Intel/более старые macOS и полный download/replace/relaunch через Sparkle здесь не повторялись.
Нативный прогон использовал внутрипроцессные действия и изолированный override контраста,
без изменения системных настроек. Production event data не использовались как fixtures.
