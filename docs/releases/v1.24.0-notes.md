# Countdown Manager 1.24.0 — поиск по подзадачам

Помните дело, но забыли дату? Введите слово в поле **«Поиск событий и дел»** в большом окне.
Поиск находит совпадения в названиях, заметках и подзадачах, включая выполненные дела
и дела в сохранённых прошедших событиях.

- В сетке и ленте под названием события виден короткий фрагмент найденной подзадачи.
- В деталях остаётся полный чек-лист. Совпавший текст выделяется терракотовым цветом
  с исходным размером и начертанием.
- Поиск обновляется при вводе. Очистка поля возвращает полный список.

Обновиться можно через **Настройки → Проверить обновления…**.
