# 1.20.1 — исправлено обновление из большого окна

Исправлена установка обновлений из настроек основного окна. Кнопка **«Установить и перезапустить»** теперь завершает обновление без перехода в мини-панель и ручного закрытия настроек.

Открытый редактор, сохранение данных, работающий таймер и экспорт диагностики по-прежнему откладывают перезапуск. Сохранение событий после даты, ссылки, файлы и текстовые вложения работают как в 1.20.

### Как установить этот патч из 1.20.0

Надёжный путь для текущей версии: откройте **Настройки в мини-панели → «Проверить обновления…»**, затем скачайте и установите обновление.

Если обновление уже скачано из большого окна, закройте его настройки перед нажатием **«Установить и перезапустить»**. Первую установку патча выполняет ещё старая версия с багом; после установки исправление будет работать для следующих обновлений.

Для ручной установки скачайте `CountdownManager-1.20.1-37.zip`.

**1.20.1, сборка 37 · Apple Silicon · macOS 13+.**

Встроенный экран **«Что нового»** обновлён. Открыть его повторно можно через **Настройки → Что нового…**.
